# Multi create Time Schedule Calendar

JobManage makes it possible to associate/add a [timeschedule](../jobmanager-calculations/time-schedule.md) to a group of employees simultaeously (at the same time).

It is possible to set a limited periode or just set the start date without filling out the end date.

It is also possible to overlap two periods by using the field _Prioritized_

To be used to Multi create certain schedules as the SH Schedule for a certain group of employees or to alter at schedule for a group from evening shift to night shift.

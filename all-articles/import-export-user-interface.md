# Import/Export User Interface

# IMPORT

The import will **override** the values on the **the marked line**, even if the file is from another _Key_. The is the fields: `Type`, `Relation` og `Only Mobile`.

During Import a prompt ask if _Override...?_  
If the _Key_ is _different_, the dialog will inform that it's from another User Interface.

Import kan _only_ be done to and existing User Interface.

# EXPORT

Export an User Interface creates a XML file with all fields.

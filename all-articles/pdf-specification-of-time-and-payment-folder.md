# PDF - Specification of Time and Payment (Folder)

JobManager can print the Specification of Time and Pay Lines to a specific drive and folder.

With older NAV installations, a file is created per employee.

With newer BC installations, a Zip file is created.

**Setup under the Destination tab**

The path to the drive and folder is registered in the ZIP File Name field

Ex. C:- Company

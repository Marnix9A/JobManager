# Registration Cockpit

Enter Employee-Id, then there can be registred on Jobs. This is done either by entering the Job-Id or choose from the list.

An action must **always** be _confirmed_ with **Commit**.

_Both Employee-Id and Job-ID can either be typed or scanned with bar-codes._

At the bottom is a _cue indicator_ with the current [Active Jobs](../all-pages/active-jobs.md).

Shortcut to open the page direct from a shortcut: `http://TheServer:8080/BC/?Page=6182710&Mode=Edit`

**Appearance and features may vary depending on configuration!**

| Action | Description |
| :-- | :-- |
| Commit | Confirm the action. |
| Cancel | Cancel the current action. |
| Clock-in | Click to clock-in. |
| Clock-out | Click to clock-out. |
| Break start | Click to start a break. |
| Break stop | Click to stop a break. |
| Teams | Teams are chosen when you want to access as an assistant to another employee who is already working on a job. |
| Balance | View the relevant balances for the current employee. Eg., vacation, Special vacation and flex balance. |
| Statistics | Setup statistics, eg. to show the registration history |
| Absence | Click when you wish to see/request future absence. |
| More Functions | There may be associated additional special functions. |
| Messages | It is possible to write/receive a message to/from another employee or foreman. |

| Job List | Description |
| :-- | :-- |
| IPC | Select IPC job. Show the available jobs of type IPC. |
| Production | Select Production job. Show the available jobs of type Production. |
| Job | Select Job job. Show the available jobs of type Job. |
| Service | Select Service job. Show the available jobs of type Service. |
| Assembly | Select Assembly job. Show the available jobs of type Assembly. |

| Registration Overview | Description |
| :-- | :-- |
| Selected | Shows the number of jobs marked for start registration. Choose _Commit_ to actually start them. |
| Active Jobs | Shows active jobs. |

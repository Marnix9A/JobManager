# JobManager Answer Collection

An _Answer Collection_ is one reply to a [Questionnaire](./jobmanager-questionnaire.md). The individual answers for each Question is found in [Answer Collection Lines](../all-tables/jobmanager-answer-collection-line.md).

An _Answer Collection_ can be held open, which allows answering the individual questions over time - even by different employees. The field [Answered](./answered.md) indicates whether everything has been answered.

An _Answer Collection_ can be approved.

An overview of the JobManager Questionnaire Module can be found [here](./questionnaire.md).

As a respondent/user, you have the opportunity to follow whether the questionnaire has been answered/created by someone else, created without job registration, whether it has been fully answered, or the user has answered/created the form himself.

The rules for the colors:

| Color and font | Description |
| :-- | :-- |
| Blue | Created from a job _without_ jobregistration and fully answered. |
| **Blue (bold)** | Created from a job _without_ jobregistration and **not** fully answered. |
| Black | Created from _this_ jobregistration and fully answered. |
| **Black (bold)** | Created from _this_ jobregistration and **not** fully answered. |
| Orange | Created from _another_ jobregistration and fully answered. |
| _Red (italic)_ | Created from _another_ jobregistration and **not** fully answered. |

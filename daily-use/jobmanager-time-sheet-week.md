# JobManager - Time Sheet (Week)

Here you can register times for 7 days at a time.

**Appearance and features may vary depending on configuration!**

| Function | Description |
| :-- | :-- |
| Prev. Week | Moves to the previous week. |
| Prev. Day | Moves to previous day. |
| Next Day | Moves to next day. |
| Next Week | Moves to next week. |
| Statistics | Setup statistics, eg. to show the registration history |
|  |
| Balance | View the relevant balances for the current employee. For example, Vacation, Special vacation, and flex balance. |
| Absence | Click when you wish to see/request future absence. |
| Messages | It is possible to write/receive a message to/from another employee or foreman. |

Bottom part shows:

*   **Weekday**
*   **Status**
    *   If day is [Time Calculated](./calculated.md) or [Approved](./approved.md).
*   **Copy from another day**
    *   Copy registrations from another day.
    *   Related Mileage, Registration add-on and Item Consumption are **NOT** included.
    *   The function is activated by pressing the small button in the field.
*   **More Functions**
    *   There may be associated additional special functions.
    *   These could be setup in _Custom Signing Functions_.  
        
    *   The function is activated by pressing the small button in the field.
*   **Expected**
    *   Shows the expected hours.
*   **Hours**
    *   Sums the registered hours.

The rest is the jobs that can be used for registration. Jobs are displayed if:

*   There are registrations on the job for the specified period
*   The job is listed in [Favorite Jobs](../general-setup/favorite-jobs.md). _These can be added by selecting the "Favorite" field._

New jobs can manually be added by creating a new line.

Hours are to be entered for the job below the individual dates.

**You can choose to see the lines behind the hours by pressing the small button in the field. From here there is access to fill in more fields, create a line more on the same job and other functions.**

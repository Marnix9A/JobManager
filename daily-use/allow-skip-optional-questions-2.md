# Allow skip optional questions

Indicates whether it is allowed to mark a questionnaire as "Answered" even if optional questions are missing.

Closing the questionnaire page will ask if the questionnaire should be marked as "Answered" if only optional questions are missing.

A question is considered _optional_ if both [Minimum (validation)](./minimum-validation.md) and [Maximum (validation)](./maximum-validation.md) are _blank_ on the [Question](./jobmanager-question.md).

# Ref. Type

If a Answer Collection is answered through JobManager, it relates to a [JobManager Job](../general-setup/jobmanager-job.md). This reference is stored in _Ref. Type_, _Ref. Number_, _Sub. Ref. Number_ and _Job Id_.

It can also be answered in connection with a specific [Stamp Journal Line](../all-tables/stamp-journal-lines-2.md). This reference is stored in _Journal Reference_.

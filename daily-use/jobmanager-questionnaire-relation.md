# JobManager Questionnaire Relation

In order for an employee to answer a [Questionnaire](./jobmanager-questionnaire.md) it must be set up in this table.

Relation is made to the individual _modules_. If the releation is for _Production_, further restrictions can be set on selected fields.

An overview of the JobManager Questionnaire Module can be found [here](./questionnaire.md).

# JobManager - Time Sheet

Post hours by entering registrations every day. First select the desired Day. Choose **Edit** and enter the desired registrations. In the end save the lines with **Commit**. _This could be deactivated [here](./hide-edit-commit.md)._

Basically time are registered as Start and Stop time. Alternative it can be registered as [Hours](./hours.md). _This field is hidden by default._

If registration is in hours, total hours pr day, is shown in at the top of the timesheet. Mileage will also be shown here.

**Appearance and features may vary depending on configuration!**

| Function | Short-cut | Description |
| :-- | :-- | :-- |
| Prev Day | F7 | Move to the previous day. |
| Next Day | F8 | Move to the next day. |
| Up | Pil op | Move up (previous line). |
| Down | Pil ned | Move down (next job). |
| Edit | F11 | Open Journal for edit. |
| Commit | F9 | Confirm and save the changes. |
| Clock-in | Ctrl+1 | Insert Clock-in registration. |
| Clock-out | Ctrl+2 | Insert Clock-out registration. |
| Break | Ctrl+3 | Insert Break registration. |
| Copy from another day | Ctrl+K | Copy registrations from another day. Related Mileage, Registration add-on and Item Consumption are **NOT** included. |
| Quick entry | Ctrl+l | to quickly insert lines from favorites and previouly registrations, skips the jobs from history if the job is marked as _Disable registration_ |
| IPC | Ctrl+I | Pick Indirect Production Cost. Show a list of Jobs of Type IPC. |
| Production | Ctrl+P | Pick Production. Show a list of Jobs of Type Production. The jobs can be further filtered by choosing a specific Work Center or Machine Center. |
| Job | Ctrl+J | Pick Job No. Show a list of Jobs of Type Job. The job be further filtered by choosing a specific Resource Group or Resource. |
| Service | Ctrl+S | Pick Service. Show a list of Jobs of Type Service. The job be further filtered by choosing a specific Resource Group or Resource. |
| Reporting | Ctrl+R | Repport Status and Qty for the Job. |
| Questionnaire | Ctrl+Alt+Q | Click to fill out the Questionnaire. |
| Mileage |  | Click to register milage. From Eg. company to customer |
| Statistics |  | Setup statistics, eg. to show the registration history |
| Balance | Ctrl+B | View the relevant balances for the current employee. For example Vacation, Special Vacation and Flex Balance. |
| Absence |  | Click when you wish to see/request future absence. |
| Messages |  | It is possible to write/receive a message to/from another employee or foreman. |
| More Functions |  | There may be associated additional special functions. These could be setup in _Custom Signing Functions_. |

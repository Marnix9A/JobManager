# JobManager - Registration Client

Enter Employee-Id, then there can be registred on Jobs. This is done either by entering the Job-Id or choose from the list.

Jobs are selected with **Select Job**. If selection is repeated on several Jobs, the Jobs are bundled together. With **Continue bundle** the new selection of Job(s) are added to the existing active jobs in a bundle.

An action must **always** be _confirmed_ with **Commit**.

_Both Employee-Id and Job-ID can either be typed or scanned with bar-codes._

At the bottom is a list of the current [Active Jobs](../all-pages/active-jobs-registration-client.md).

The page have a _hidden_ field **Comments**, which can show if any comments on the job. Read [here](./highlight-comments.md) for further information.

**Appearance and features may vary depending on configuration!**

| Action | Short-cut | Description |
| :-- | :-- | :-- |
| Commit | F9 | Confirm the action. |
| Cancel | Ctrl+Q | Cancel the current action. |
| Select Job | F11 | Select the job, currently selected on the list. Selected jobs have a green text color. |
| Up | Arrow Up | Move up (previous job). |
| Down | Arrow Down | Move down (next job). |
| Filter selected | Ctrl+F | If you select one or more jobs (eg for bundling) then you can with filter selected, have limited view to show only the lines you have selected (before accepting) the lines will be the lines you have said select job for (and the lines will be highlighted in green text.) |
| Continue Bundle | Ctrl+U | If you have one or more ongoing active jobs and want to add one or more jobs to existing ones. First select the jobs you want and then continue bundle before pressing accept. This will join the active and selected jobs in a new bundle. |
| Clock-in | Ctrl+1 | Click to clock-in. |
| Clock-out | Ctrl+2 | Click to clock-out. |
| Break | Ctrl+3 | Click to start a break, if needed. |
| Team Start | Ctrl+4 | Click to be an assistant to another employee, who are already working on a job. The employee who is selected will be a pilot. |
| Team Stop | Ctrl+5 | Used to opt out of a team. Only assistants can leave a team, pilots cannot. |
| Show Team | Ctrl+6 | If teams are running, this will show the currently running teams with pilots and assistants. |
| IPC | Ctrl+I | Show IPC Jobs in the job list. |
| Production | Ctrl+P | Show Production jobs. The jobs can be further filtered by choosing a specific Work Center or Machine Center. |
| Job | Ctrl+J | Show Jobs in the job list. The job be further filtered by choosing a specific resource group or resource. |
| Service | Ctrl+S | Show Service Jobs in the job list. |
| Assembly | Ctrl+Y | Show Assembly Jobs in the job list. |
| Pick Work Center | Ctrl+W | Filter the job list on a specific Work Center. It is possible to select one or more. |
| Pick Machine Center | Ctrl+M | Filter the job list on a Machine Center. It is possible to select one or more. |
| Pick Ressource Group | Ctrl+W | Filter the job list on a Resource. It is possible to select one or more. |
| Pick Ressource | Ctrl+R | Filter the job list on a Resource Group. It is possible to select one or more. |
| Search | F4 | Search for Production/Job/Service etc. |
| Comments | F12 | Show Comments and Files for the Job. |
| Balance | Ctrl+B | View the relevant balances for the current employee. Eg., Vacation, Special vacation, and flex balance. |
| Statistics |  | Setup statistics, eg. to show the registration history |
| Absence |  | Click when you wish to see/request future absence. |
| Questionnaire | Ctrl+Alt+Q | Click to fill out the Questionnaire. |
| Messages |  | It is possible to write/receive a message to/from another employee or foreman. |
| More Functions |  | There may be associated additional special functions. |

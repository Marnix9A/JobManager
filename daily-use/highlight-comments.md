# Highlight Comments

[JobManager - Registration Client](./jobmanager-registration-client.md) have a _hidden_ field **Comments**, which can show if any comments on the job.

This field determines whether _this_ comment should be included. It should only be activated, **if** the above field is displayed - and perhaps only for some special comments.

Enabling this field _can_ provide _slightly_ poorer performance on the Registration Client.

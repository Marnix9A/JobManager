# JobManager Questionnaire

Use this table to create Questionnaires, which is a combination of [Questions](./jobmanager-question.md) associated in [Questionnaire Lines](../all-tables/jobmanager-questionnaire-line.md). _Questions can be used in several different Questionnaires._

A questionnaire can be answered and saved in an [Answer Collection](./jobmanager-answer-collection.md). In order for an employee to answer a questionnaire, [relations](./jobmanager-questionnaire-relation.md) must be set up.

An overview of the JobManager Questionnaire Module can be found [here](./questionnaire.md).

# Questionnaire

JobManager contains a questionnaire module.

It is structured as follows:

*   Create some [Questions](./jobmanager-question.md).
*   These questions are put together in a [Questionnaire](./jobmanager-questionnaire.md).
*   A questionnaire can be answered and saved in an [Answer Collection](./jobmanager-answer-collection.md).
*   In order for an employee to answer a questionnaire, [relations](./jobmanager-questionnaire-relation.md) must be set up.
*   Answering through the pages:
    *   [Registration Cockpit](./registration-cockpit.md)
    *   [Registration Client](./jobmanager-registration-client.md)
    *   [Time Sheet](./jobmanager-time-sheet.md),
    *   [Time Sheet (Week)](./jobmanager-time-sheet-week.md)
    *   [Mobile Registration Client App](../mobile-registration-client-app/README.md)
*   The table [JobManager User Interface](../other-setup/jobmanager-user-interface.md) has a [field](./hide-questionnaire.md) to disable answering Questionnaires.
*   An _Answer Collection_ can be approved.

The [questionnaire](./jobmanager-questionnaire.md) page provides the opportunity to import and export an entire questionnaire including questions.

**The installation package for JobManager contains some examples.**

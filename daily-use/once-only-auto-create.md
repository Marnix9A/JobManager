# Once only (Auto Create)

If this is checked, a given questionnaire (Id) will only be inserted **once** in the given _Where_.

For productions furthermore limited with the fields [Production Setup Time (Auto Create)](./production-setup-time-auto-create.md), [Production Run Time (Auto Create)](./production-run-time-auto-create.md), [Production Wait Time (Auto Create)](./production-wait-time-auto-create.md) and [Production Move time (Auto Create)](./production-move-time-auto-create.md).

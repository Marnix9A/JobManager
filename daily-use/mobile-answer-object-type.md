# Mobile Answer Object Type

Object Type and Id on the primary Report used for printing [Answer Collections](./jobmanager-answer-collection.md) based on this questionnaire.

Default value is _Report 6183091_ which is a _list_ based Report. Optional value is _Report 6183092_ whis is a _form_ based Report.

The customer's supplier can create new Reports, which can then be specified here.

The [Answer Collection](./jobmanager-answer-collection.md) page has two _Print_ actions. One to print the this default report, and another to select which report to print. _The selection list is based on associated reports from any given Questonnaire._

from version 01.37 The answer reports for Answer Collections is able to show the attached photos

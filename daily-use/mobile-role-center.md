# Mobile Role Center

**JobManager Mobile** is a personal [Role Center](../other-setup/role-center.md) with specially designed pages for use on mobile phones running [Microsofts APP for mobile devices](https://docs.microsoft.com/en-us/dynamics365/business-central/install-mobile-app).

Select Role Center **JOBMANROLECENTERMOBILE** (X) to get an "app"-like experience on the mobile phone. _Works from Business Central version 14 and later._

**Remember to associate the NAV/BC User to a [JobManager Employee](../general-setup/jobmanager-employee.md) in the field [Username](./user-name.md).**

If using a tablet/iPad it's recommended using the **JOBMANROLECENTERREGISTRATION** (X) or other Role Center, which uses the _regular_ pages adapted to the larger displays.

(X) Some Role Centers have different names in older versions of BC/NAV. See [this](../other-setup/role-center.md) complete list.

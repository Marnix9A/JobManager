# Export payroll to external payroll systems

At the bottom of this page under _See also_ is a complete list of standard supported payroll systems. If a payroll system is missing, contact _support@jobmanager.dk_.

In JobManager, payroll and absence lines can be exported to external payroll systems. The export is generally based on 3 fields:

*   External No
*   External Type
*   External Unit

The field [Number](./number.md) indicates how the employee is identified in the export.

### General filter

*   _Transferred_: Default `No`.
*   _Settle Sequence_: Default `0` (zero).
*   _Pay Date_: Limit the start and end date of the pay period.

Other filters can be added as needed, eg _Agreement_.

### Pay Types

The Standard Calculation ID contains wage types that can be directly used in the collective agreement setup.

### Advanced

The necessary setup will be shown in the documentation for the individual payroll systems.

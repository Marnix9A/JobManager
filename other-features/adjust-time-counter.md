# Adjust Time Counter

From [JobManager Employee](../general-setup/jobmanager-employee.md) one can adjust the value of a _Time Counter_.

To allow manual adjustment of a _Time Counter_, it has to be [allowed on the Time Counter](./adjustment-allowed.md).

For help filling out the individual fields, see the [Field Help](./pay-type-for-adjustment.md).

1.  Open the **JobManager Employees** List.
2.  Select **Edit**.
3.  Select the desired Time Counter at the bottom under **Time Counters**.
4.  Select the function **Adjust Time Counter**.

The adjustments are saved in [Period Calculated Lines](../all-tables/calculated-lines.md) with a [special mark](./manual-adjustment.md).

**Please read about [Adjust Employee Balance](../all-tables/adjust-employee-balance.md), which is a more advanced way of adjusting balances.**

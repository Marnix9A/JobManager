# Permanent teams

**Setting up Permanent Teams**

It is possible to set up _Permanent Teams_ in JobManager. This is used if employees often or allways work together on Projects or machines.

(however, teams can also be accessed in Registration cockpit/client, without setting up permanent teams, if used only infrequently)

There will be a Pilot (responsible) and one or more assistants. The assistants choose to access the Pilot and then the Pilot will be the one to choose (start/stop) jobs.

ONLY assistants can resign from a team. The Pilot however can choose another employee for the role as Pilot, and then be able to resign.

The table _Permnent Teams_ contains the teams that are stored in JobManager.

Stored teams can be restarted later. They are set up [here](./permanent-teams-2.md).

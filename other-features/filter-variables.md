# Filter Variables

**The following is discontinued in standard JobManager.**

**The installation package for JobManager contains an example on how to re-implement this feature. See the file SampleEventMyEmployees.txt**

**The following only applies for NAV 2016 and later**

New Filters Variables could be used as filters in Employee No fields in Pages, Reports etc.

When using one of the Filter Variables below in a Employee No filter the relevant employes are filled by NAV.

| Filter variabel | Udfyldes med med | Eksempel |
| :-- | :-- | :-- |
| %JMGCALCULATEGROUP | Employees from the [Calculation Groups](../general-setup/employee-groups.md) the user is [responsible](../daily-use/responsible.md) for. | AH|JR |
| %JMGAPPROVEGROUP | Employees from the [Approval Groups](../general-setup/employee-groups.md) the user is [responsible](../daily-use/responsible.md) for. | AH|JR|MD |

# Q&Q (Time Calculation)

This article describes how to troubleshoot the [Time Calculation](../all-pages/time-calculation-and-approval.md) of the _Employees time_.

| Causes of Error |  |
| :-- | :-- |
| Lack of time on the Day | Enter relevant Cause of Absence |
| Lack of calculation of Time | Check Time Counters on the Schedule Type |
| Change of the Clock-In/Out time | Check setup of tolerance on the Time Schedules / Shifts |
| Inconsistence between time and Clock-out | Check whether it is allowed to have waiting jobs |

*   Setup [Time Schedules / Shifts](../all-tables/time-schedule-shifts.md)
*   Setup [Wait Job](../general-setup/wait-job-id.md)

# Import/Export Calculation

**IMPORT:**

JobManager gives the opportunity to get started quickly by importing af existing [Calculation](./README.md).

The Standard setup are imported and it contains:

*   Time Counters
*   Schedule Types
*   Time Schedules
*   Pay Counters
*   Aggrement
*   IPC Categories
*   Periods

It prompts for:

| Action on missing Jobs |  |
| :-- | :-- |
| Stop with errors | Import canceled on errors |
| Ignorere (reset Job Id) | Import but reset Job Id |

**EXPORT:**

The export contains the same things as indicated under _IMPORT_.

It prompts for:

| Prompt Value | Exported |
| :-- | :-- |
| Used | All the used Periods, Pay Types or IPC Activities |
| All | All present Periods, Pay Types or IPC Activities |
| None | No IPC Activities |

_The list of Calculations have a action **Download online**, which download and import a standard Calculation. The installation package for JobManager includes the same file._

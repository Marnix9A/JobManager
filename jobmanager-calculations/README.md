# JobManager Calculations

A _Calculation_ is a collection of settings, which is a prerequisite for the [Time Calculation](../all-pages/time-calculation-and-approval.md) of time, absence and pay.

A _Calculation_ consists of several tables containing setup of eg:

*   Counter Units
*   Schedule Types
*   Time Schedules
*   Agreetments
*   Calculation Warnings/Errors

Common to all tables is the field Calculator-ID which is the _key_.

A company typically uses _one_ calculation, but in special cases more _can_ be needed.

The possibility of multiple calculations can be useful for testing various setups where individual [employees](../general-setup/jobmanager-employee.md) are assigned to different calculations.

A _Calculation_ can be copied within the same company or [imported/exported](./import-export-calculation.md) between NAV/BC installations.

_The list of Calculations have a action **Download online**, which download and import a standard Calculation. The installation package for JobManager includes the same file._

# Function Type

The field is usually set to \*\* Count \*\*.

If the Time Schedule Lines is used on a [Time Schedule Line](../all-tables/time-schedule-lines.md) to indicate:

*   Clock-In
*   Clock-Out
*   Bread

**Function Type** must be set to the same value.

See also [here](../all-tables/skip-merge-primary.md).

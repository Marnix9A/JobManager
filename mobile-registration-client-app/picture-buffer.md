# Picture Buffer

Picture Buffer makes it possible to quickly take pictures with a telephone, which can then later be used inside NAV/BC.

Pictures chan easily be picked from the _Picture Buffer_ an associated in [JobManager Attachment](../all-tables/jobmanager-attachment.md) to:

*   a \[time registration\] (T\_6182623.htm)
*   et \[job\] (T\_6182601.htm)
*   an answer to a \[questionnaire question\] (T\_6183023.htm)

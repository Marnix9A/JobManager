# Get started with App

**Note the App below is deprecated and replaced by [this solution](../daily-use/mobile-role-center.md).** Business Central 19 is **LAST** version where the following is supported.

### Run the APP in a browser

1.  In the browser enter **`https://jmgapp.dk`**
2.  If it's the first login the _Connect device_ page is shown.
    1.  Enter **Company ID**. _(see note 1)_
    2.  Enter **Connection code**. _(see note 1)_
    3.  Press _the gear icon_ in the left top corner and select **Employee**.

### Install the APP on phone/tablet

1.  Open the standard browser
2.  Enter **`https://jmgapp.dk/install?lang=en`** _(see note 2)_ and follow the instructions to make an icon on the _Homescreen_ of the device.
3.  Close the browser
4.  Open the APP from the _new icon_ on the _Homescreen_
    1.  Enter **Company ID**. _(see note 1)_
    2.  Enter **Connection code**. _(see note 1)_
    3.  Press _the gear icon_ in the left top corner and select **Employee**.

_Note that the App's appearance are using the setup from [JobManager User Interface](../other-setup/jobmanager-user-interface.md)._

_Note 1:_ This information is provided by the NAV/BC partneren who has [created the connection](../advanced-setup/setup-mobile-app.md).

_Note 2:_ Optional parameters can be passed to the installer:

*   Change language
    *   `https://jmgapp.dk/install?lang=en`
    *   `https://jmgapp.dk/install?lang=da` .
*   Force OS help _(the installer should default correct os)_
    *   `https://jmgapp.dk/install?os=ios`
    *   `https://jmgapp.dk/install?os=android` .
*   These parameters could be combined
    *   `https://jmgapp.dk/install?lang=en&os=ios`

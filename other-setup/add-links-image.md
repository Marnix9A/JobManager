# Add links/image

**This is only for older version of NAV/BC. We recomment using [JobManager Attachments](../all-tables/jobmanager-attachment.md), which replace file links in all versions.**

If enabled, images sent from both [JobManager Mobile](../daily-use/mobile-role-center.md) and the deprecated [Mobile Registration Client App](../mobile-registration-client-app/README.md) is linked to this table.

Can be activated on **several** lines, hereby images are available from all enabled places.

The pictures are stored [here](../general-setup/path-for-new-links.md).

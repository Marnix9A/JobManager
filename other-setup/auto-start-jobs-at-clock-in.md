# Auto start Jobs at clock-in

This field indicates that selected [JobManager Jobs](../general-setup/jobmanager-job.md) are automatically started when the Employee _Clocks-In_ in the [Registration Cockpit](../daily-use/registration-cockpit.md).

The following filters will be added:

*   [Ref. Type](../general-setup/ref-type.md) must be the Employee's [Primary Work](../general-setup/primary-work.md)
*   [Date filters](./filter-ending-date-from.md)
*   [Additional filters](../general-setup/filter-option.md)

A [maximum](./max-auto-start-jobs-at-clock-in.md) can be specified.

**Note that** the following condition must be met for the field to be activated:

*   The field [Restart at clock-in](./restart-at-clock-in.md) must be _deactivated_.
*   A filter should be applied in [Filter Starting Date](./filter-starting-date-from.md) _(both from and to)_ and/or in [Filter Starting Date](./filter-starting-date-to.md) _(both from and to)_

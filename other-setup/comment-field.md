# Comment Field

Table Number for the related table.

*   If [Type](./ref-type.md) is **Comment** this is the Field Numnber for the field in _Comment Table_ holding the comments.
    
*   If [Type](./ref-type.md) is **Link** this is not filled in.
    
*   If [Type](./ref-type.md) is **Codeunit** this is not filled in.

# Filter Starting Date (From)

The filter fields below are used for showing jobs in the pages:

*   [JobManager – Registration Cockpit](../daily-use/registration-cockpit.md)
*   [JobManager - Registration Client](../daily-use/jobmanager-registration-client.md)
*   [JobManager - Time Sheet](../daily-use/jobmanager-time-sheet.md)
*   [JobManager - Time Sheet (Week)](../daily-use/jobmanager-time-sheet-week.md)

The filters also applies to [Mobile registration Client App](../mobile-registration-client-app/README.md).

The following fields could be used:

[JobManager User Interface table](./jobmanager-user-interface.md)

*   Filter Starting Date (From)
*   Filter Starting Date (To)
*   Filter Ending Date (From)
*   Filter Ending Date (To)

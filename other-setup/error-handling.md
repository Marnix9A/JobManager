# Error handling

Select how information and error messages are shown in the registration pages:

*   **Standard NAV** shows a yellow bar with text which require an **F5** key press to cancel/contunie.
*   **Info box** showsa pop-up box, which is closed with **ENTER** or _OK_ button with the mouse.
*   **Timer Box** shows a pop-up box for a number of seconds before it is automatically closed. Also fill in: [Error Seconds](./error-seconds.md) and [Info Seconds](./info-seconds.md).

The field value is also used on [Leave warning](../general-setup/leave-warning.md) and [11 hour rule](../q-and-a-questions-and-answers/q-and-a-11-hours-rule.md).

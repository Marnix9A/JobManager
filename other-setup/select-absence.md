# Select absence

Enables asking the Employee for the reason for [Absence](../all-tables/ipc-activity.md). This occurs if the employee _is lat_e or _leaving early_ compared to the [Time schedule](../jobmanager-calculations/time-schedule.md).

| Option | Description |
| :-- | :-- |
| None | Employee can _not_ choose absence. |
| Force | Employee **must** choose absence. The list appears if the employee has Clocked-In to late or Clocked-Out too early. |
| Optional | Employee **can** choose absence. The list appears if the employee has Clocked-In to late or Clocked-Out too early. |
| Always show | Employee **can** choose absence. The list appears always at Clock-In/Clock-Out. |

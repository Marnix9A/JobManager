# Filter Registration add-on

Filter the records in [Registrations add-on](../general-setup/registration-add-on.md) upon registration in [Stemp Journal add-on](../all-tables/stamp-journal-add-on.md).

This filter _can_ overruled by [Filter Registration add-on](../general-setup/filter-registration-add-on.md) set up on the employee.

**Read [here](../all-articles/filter-input.md) to learn about the _syntax_ for filters.**

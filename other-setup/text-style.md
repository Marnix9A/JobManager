# Text Style

Both the **Caption** and the **text** can be highlighted.

The options below are the same as those used widely in NAV.

| ID | Bold | Italic | Color |
| :-- | :-: | :-: | :-: |
| Standard |  |  | Black |
| StandardAccent |  |  | Blue |
| Strong | X |  | Black |
| StrongAccent | X |  | Blue |
| Attention |  | X | Red |
| AttentionAccent |  | X | Blue |
| Favorable | X |  | Green |
| Unfavorable | X | X | Red |
| Ambiguous |  |  | Orange |
| Subordinate |  |  | Gray |

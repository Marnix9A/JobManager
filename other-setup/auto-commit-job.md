# Auto commit job

When this is activated the registration is automatically **Committed**.

**NOTE**: [Stop-kode](../advanced-setup/stop-code.md) on the _previous_ Job is automatically set to the value of [this setup value](../general-setup/obsolete-default-stop-code.md).

_NOTE: This does **not** interact with bundling._

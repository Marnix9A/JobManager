# Type

*   **Comment** is used to collect _Comments_ from related tables.
*   **Link** is used to collect _Links_ from related tables.
*   **Codeunit** is used to add entirely different _Comments_ and/or _Links_. That could be from a new table.

**Further information [here](./comments-setup.md).**

By using _Codeunit_ one **avoids** changes to JobManager objects, making updating JobManager versions much easier. _The installation package for JobManager contains some examples._

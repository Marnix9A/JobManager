# Allow close page

Normally the register windows **can't** be clossed. This field can override this feature, so that the Employe _can_ close the register windows.

If the _Employee No_ **000** is entered, it will alway close.

Furthermore, the page will always close if the User is found within on of these [Permission Sets](./set-default-permissions.md):

*   SUPER
*   JOBMAN-FOREMAN
*   JOBMAN-ADMINISTRATOR

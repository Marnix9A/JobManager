# Field on Job Table (4)

There are 5 available filters. They are used to filter on the [Reference Table](./reference-table.md).

This Field is a _Field Number_ on [the Table with Jobs](../general-setup/jobmanager-job.md). The Value of the _Field_ are assigned to [this filter](./field-on-reference-table-1.md).

If this field is _empty_ fill in a [Constant](./constant-1.md) instead.

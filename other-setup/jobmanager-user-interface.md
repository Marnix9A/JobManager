# JobManager User Interface

A number of parameters define the user experience for registration.

Search:

1.  User Interface for **User** (eg a specific _terminal_)
2.  User Interface for **Permission Set** (eg a number of _terminals_)
3.  User Interface for **Employee**
4.  User Interface for **Employee Group**
5.  User Interface for **All**

For 1 and 2 applies, the search can be forced to [stop here](./stop.md). Otherwise it searches forward.

For 3, 4 and 5 the following applies for legacy [Mobile registration Client App](../mobile-registration-client-app/README.md). First, test if there are lines marked with [Only App](./only-mobile.md). Subsequently search without.

An _User Interface_ can be copied within the same company or [imported/exported](../all-articles/import-export-user-interface.md) between NAV/BC installations.

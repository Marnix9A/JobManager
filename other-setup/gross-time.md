# Gross Time

| Gross Time | Excl. Break | Time to post |
| :-- | :-- | :-- |
| Yes | No | All the time from the registration (start to end). _That is **before** [bundle allocation](./bundle-allocation.md)_. |
| Yes | Yes | All the time from the registration (start to end). _That is **before** [bundle allocation](./bundle-allocation.md)_. From here, _breaks_ are deducted. |
| No | No | The time is the same as the corresponding registration. The time after any [bundle allocation](./bundle-allocation.md) from which _breaks_ already _are_ deducted. |
| No | Yes | _Combination not possible!_ |

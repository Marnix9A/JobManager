# Field on Reference Table (1)

There are 5 available filters. They are used to filter on the [Reference Table](./reference-table.md).

*   If [Type](./ref-type.md) is **Comment** this is _Key Fields_ in the _Comment Table_.
    
*   If [Type](./ref-type.md) is **Link** this is _Key Fields_ in Table with relation to the Links.
    
*   If [Type](./ref-type.md) is **Codeunit** this _can_ be omitted. If desired it _can_ be used by the _Codeunit_, as this have access to these values.
    

_Look at the existing setup for samples._

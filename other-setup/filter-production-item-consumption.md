# Filter Production (Item Consumption)

Use this filter on [Item Consumption](../all-pages/item-consumption.md) from the [JobManager - Registration Client](../daily-use/jobmanager-registration-client.md).

| Option | Description |
| :-- | :-- |
| Show all items | Show all items for the _entire_ Production Prder. |
| Filter on Routing Link Code | Show only items for the related Routing Link Code. |
| Filter on Prod.Order Line | Show only items for the related Prod.Order Line. |

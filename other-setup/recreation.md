# Recreation

Uses for e.g. 11 hour rule.

It is possible for the employee to recieve a warning/error in the Cockpit/Client, when the _Recreation period_ is not kept. The Warning/error comes, when they have filled in the employeenumber.

*   None - No warning.
*   Warning - There comes a pop-up, when they have typed in the empolyeenumber, in Cockpit/Client, if the employee hasn't kept the recreation periode. But they can continue registrate time.
*   Error - If the employee hasn't kept the recreation periode, there comes an _Error_ pop-up, when they have typed in the empolyeenumber in Cockpit/Client. And the employee **CAN'T** registrate time, before the recreation periode is kept.

This function can only be used is the employee use Clock-in/Clock-out.

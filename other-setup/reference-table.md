# Reference Table

Table Number for the related table.

*   If [Type](./ref-type.md) is **Comment** this is the _Comment Table_ holding the comments.
    
*   If [Type](./ref-type.md) is **Link** this is the table with reference to the Links.
    
*   If [Type](./ref-type.md) is **Codeunit** fill in the Object Number.
    

_Look at the existing setup for samples._

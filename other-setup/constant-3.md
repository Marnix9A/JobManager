# Constant (3)

There are 5 available filters. They are used to filter on the [Reference Table](./reference-table.md).

This Field is a _Fixed Filter Value_. The value is assigned to [this filter](./field-on-reference-table-1.md).

If this field is _empty_ fill in a [Field Number](./field-on-job-table-1.md) instead.

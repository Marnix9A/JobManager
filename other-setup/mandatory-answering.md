# Mandatory Answering

This field indicates how _restrictive_ the field [Mandatory Answering](../daily-use/mandatory-answering.md) on [Questionnaire Relation](../daily-use/jobmanager-questionnaire-relation.md) should be:

*   **(blank)** means no warning/blocking.
*   **Warning** means that `Accept` will warn, if there are associated Answer Collections marked with [Mandatory Answer](../daily-use/mandatory-answering.md).
*   **Force** means that `Accept` will interrupt/fail, if there are associated Answer Collections marked with [Mandatory Answering](../daily-use/mandatory-answering.md).

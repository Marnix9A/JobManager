# Default Stop-code

Indicates what to do with the _Active Jobs_ when an Employee register on _new Jobs_. The value is written in [this field](../advanced-setup/stop-code.md).

| Value | Description |
| :-- | :-- |
| Pick | The Employee must choose one of the following. |
| Stop Time | This field is automatically set to this. |
| Finish | This field is automatically set to this. |

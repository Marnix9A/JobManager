# Bundle allocation

If an employee has registered on multible jobs at the same time (overlap/bundles), it is necessary for the time calculator, to allocate and distribute time on the different registrations.

Use this table to setup the type of [allocation](./calc-method.md), that should be used, if registration is made on several jobs at the same time.

You can set up an allocation key for each individual job type.

# Post time (Flushing Method=Forward)

Postring time consumption to _Produktion_ can be limited, if _Flushing Method_ is _Forward_ or _Backward_:

| Valgmulighed | Handling |
| :-- | :-- |
| Yes | Time consumption are posted as normal |
| No | Time consumption are **NOT** posted |
| Yes (Skip Unit Cost) | Time consumption are posted with **Unit Cost=0** |

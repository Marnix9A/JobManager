# Path for new links

**This is only for older version of NAV/BC. We recomment using [JobManager Attachments](../all-tables/jobmanager-attachment.md), which replace file links in all versions.**

Images sent from both [JobManager Mobile](../daily-use/mobile-role-center.md) and the deprecated [Mobile Registration Client App](../mobile-registration-client-app/README.md) are stored in this path.

Furthermore is should be activated [here](../other-setup/add-links-image.md) where to link.

**Use UNC path - eg. `\\MyServer\JobManagerImages\`. The NAV/BC Sercie User should have write permission and others at least read permission.**

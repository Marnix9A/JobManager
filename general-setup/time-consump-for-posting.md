# Time Consump for posting

The field specifies how registrations are [posted to NAV](../daily-use/post-to-nav-bc.md).

The field is inherited to the same field on [Stamp Journal Lines](../all-tables/stamp-journal-lines-2.md).

| Option | Action |
| :-- | :-- |
| Standard | Posting the time from this field [Time Comsump](../all-tables/time-comsump.md). |
| Stamp Time (Gross) | Posting the time from this field [Stamp Time (Gross)](../all-tables/stamp-time-gross.md). |
| Stamp Time (Net) | Posting the time from this field [Stamp Time (Net)](../all-tables/stamp-time-net.md). |

The value can be adjusted with [this field](./factor-for-posting.md).

# Employee Setup

All employees or resources are created in the [Human Resource module](https://docs.microsoft.com/en-us/dynamics365/business-central/hr-how-register-employees).

JobManager uses the following fields from there:

| Field | Remark |
| :-- | :-- |
| No. |  |
| First Name | (and the other Name fields) |
| Employment Date | Should be filled if [seniority is used for calculations](../all-tables/agreement-pay-counters.md) in JobManager. |
| Resource No. | Enter an Employee Resource. |

Subsequently, _attached_ the Employees to the table [JobManager Employee](./jobmanager-employee.md) where further information specified.

# Mobile Captions

This field is a _filter_ that limits which languages ​​for which [Captions](../all-tables/mobile-captions.md) should be created in [Mobile Pages](../all-tables/mobile-pages.md).

The filter helps to speedup [JobManager Foundation Setup Guide](./jobmanager-foundation-setup-guide.md).

The default value is the language of the user who first ran [JobManager Foundation Setup Guide](./jobmanager-foundation-setup-guide.md) and English `1033`.

Example for Danish and English: `1030|1033`.

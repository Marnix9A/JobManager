# Period

Relevant periods must be created before operation. Below is an example of relevant periods:

| Period | Description | Period length |
| :-- | :-- | :-- |
| 20Y | Infinite period | 20Y |
| DAY | Day | 1D |
| WEEK | Weekly | 1W |
| YEAR | Yearly | 1Y |
| 14DAYSEW | 14 days, start equal week number | 14D |

The example shows a set of typical periods needed. The period 20Å is used as an infinite period, and can be used to control a flex-balance in an undetermined amount of time. With this feature, it is not needed to transfer balances from one year to the next.

**Note! Periods are not allowed to be changed after operation of the system has started**

Created, but never used periods, can be deleted, however, any associations on time counting units/pay counting units must be deleted, before this can be done.

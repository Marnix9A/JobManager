# Inserted Trigger

Must be filled out with a Job-ID (Trigger)

Can be used for e.g. Per Diems, or other calculations - where a calculation between start and stop i needed.

This _Inserted Trigger_ will be triggered when a start and stop trigger is found, and then the Add-on will be inserted.

# PIN-code

PIN-code for the employee for certain features:

*   Show [balance](../other-setup/balance-pin-code.md)
    *   [JobManager - Registration Client](../daily-use/jobmanager-registration-client.md)
    *   [JobManager - Time Sheet](../daily-use/jobmanager-time-sheet.md)
    *   [JobManager - Time Sheet (Week)](../daily-use/jobmanager-time-sheet-week.md)
    *   [Mobile registration Client App](../mobile-registration-client-app/README.md)
*   [Authorization](../other-setup/registration-pin-code.md) of employee
    *   [JobManager - Registration Client](../daily-use/jobmanager-registration-client.md)
    *   [JobManager - Time Sheet](../daily-use/jobmanager-time-sheet.md)
    *   [JobManager - Time Sheet (Week)](../daily-use/jobmanager-time-sheet-week.md)
    *   [Mobile registration Client App](../mobile-registration-client-app/README.md)

**Note:**

*   It is recommended only to use digits (0-9)
*   It can be 20 characters long
*   It **does not** distinguish between uppercase and lowercase letters

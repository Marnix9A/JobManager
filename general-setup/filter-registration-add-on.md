# Filter Registration add-on

Filter the records in [Registrations add-on](./registration-add-on.md) upon registration in [Stemp Journal add-on](../all-tables/stamp-journal-add-on.md).

This filter **overrules** [Filter Registration add-on](../other-setup/filter-registration-add-on.md) in _JobManager User Interface_.

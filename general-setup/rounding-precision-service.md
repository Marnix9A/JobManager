# Rounding Precision (Service)

This parameter is used to set up _round off_ scenarios for the posting time to NAV.

It will cause the system to round up, or round down to the nearest X minutes.

E.g. if all posted times should be rounded up to the nearest 15 minutes, the setting in the two fields should be **15 minutes** and **Up**.

# JobManager Job

This table contains a list of all the JobManager jobs that can be used for registration.

They are automatically created/updated when creating new or changed a Production, Job, Service Order or Assembly Order.

The field [Ref. Type](./ref-type.md) indicates from where the job were created.

Furthermore the table has a line for each [IPC](../all-tables/ipc-activity.md).

Jobs can be prioritized in [Job Priority](../other-features/job-priority.md).

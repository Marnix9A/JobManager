# Allow Posting Description

Allow Posting Description for this job.

The following rules apply by default.

Allowed for jobs of type:

*   Job
*   Service

The rules can be overridden with the **Edit** function on the _JobManager Jobs_ list, or with code by using [OnAfterInsertUpdate???2JobMan](../advanced-setup/code-customization.md).

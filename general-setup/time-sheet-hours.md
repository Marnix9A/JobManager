# Time Sheet (hours)

How the specified hours, if the employee enters time as _hours_:

*   **Gross** to enter consumed time spent from start to end. [Time Calculation](../all-pages/time-calculation-and-approval.md) will then deduct any breaks.
*   **Net** enter exact consumed time.

Used in conjunction with the field [Hours](../daily-use/hours.md) on [Time Sheet](../daily-use/jobmanager-time-sheet.md) and always on [Time Sheet (Week)](../daily-use/jobmanager-time-sheet-week.md). **Note the field is default _hidden_ on the page.**

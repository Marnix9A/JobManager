# Job

If enabled [JobManager Jobs](./jobmanager-job.md) are created for the respective type.

This can be limited for **Production** with [Skip Flushing Method=Forward](./skip-flushing-method-forward.md) and [Skip Flusing Method=Backward)](./skip-flushing-method-backward.md).

This can be limited for **Job** with the tree [Skip Line Type=?](./skip-line-type.md)fields.

# Allow Item Consumption

Allow Item Consumption for this job.

The following rules apply by default.

Allowed for jobs of type:

*   Production
*   Job
*   Service

The rules can be overridden with code by using [OnAfterInsertUpdate???2JobMan](../advanced-setup/code-customization.md).

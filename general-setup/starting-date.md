# Starting Date

Specifies when the jobs is set to respectively start and stop.

| Field | IPC | Production | Job | Service Line | Service Order Allocation | Montageordre |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| Startdato | n/a | Starting Date from Prod. Order Routing | Planning Date from Job Planning Line | Planned Delivery Date from Service Line | Allocation Date from Service Order Allocation | Starting Date from Assembly Header |
| Starttidspunkt | n/a | Staring Time from Prod. Order Routing | n/a | n/a | Starting Time from Service Order Allocation | n/a |
| Slutdato | n/a | Ending Date from Prod. Order Routing | n/a | n/a | Allocation Date from Service Order Allocation | Due Date from Assembly Line |
| Sluttidspunkt | n/a | Ending Time from Prod. Order Routing | n/a | n/a | Finishing Time from Service Order Allocation | n/a |

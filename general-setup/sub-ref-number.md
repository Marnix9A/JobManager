# Sub. Ref. Number

Indicates the related number depending on the field **Ref. Type**:

| Ref. Type | Sub. Ref. Number |
| :-- | :-- |
| IPC | No. of the IPC Activity |
| Production | Item No. of the Production Order Line |
| Job | No. of the Job Planning Line |
| Service | Item No. of the Service Item |
| Assembly | Item No. of the Assembly Order |

# Filename

File name format

**Filename: standard is set up as follows;**

For example: **Payroll\_\[YYYY\]\[MM\]\[DD\].csv**

It is possible to use various variables. \[YYYY\] year with 4 digits

\[YY\] year with 2 digits

\[WW\] week with 2 digits

\[W\] week with 1-2 digits

\[MM\] month with 2 digits

\[M\] month with 1-2 digits

\[MONTH\] month written with letters

\[DD\] date with 2 digits

\[D\] date with 1-2 digits

The variables mentioned below are used in connection with the Specification of Time and Payment.

\[EMP\] Employee number. \[#\] \[##\] \[###\]…. Adds a sequential counter number for each operational run. The number of # signs define the amount of prefixed 0’s.

# Make demodata

Demodata are for _sandbox/demo_ environment where the JobManager functionality can be tested.

1.  select a _Cronus_ Company
2.  Select the menu **Make demodata** in the **JobManager Setup** page.

| It creates the following |
| :-- |
| Run [Set default permissions](../other-setup/set-default-permissions.md). However, it is recommended to run demo with SUPER user. |
| Run the guide for [JobManager Foundation Setup](../general-setup/jobmanager-foundation-setup-guide.md) |
| Sets the NAV default Role Center to [JobManager Production Role](../other-setup/role-center.md) |
| Creates [JobManager Jobs](../general-setup/jobmanager-job.md) on existing Productions, Jobs and Service Orders from _CRONUS_ |
| Imports [Calculation](../jobmanager-calculations/README.md) to JobManager from an online server. |
| Creates two [Calculation Groups](../general-setup/employee-groups.md) _G1_ and _G2_ |
| Creates one [Approval Group](../general-setup/employee-groups.md) |
| Assign [Employees to JobManager](../general-setup/jobmanager-employee.md) |
| Creates [Period Lines](../all-tables/period-line.md) some years ahead |
| Creates [User Interface](../other-setup/jobmanager-user-interface.md) for use in demo |

**If a demo with [Mobile Registration Client App](../mobile-registration-client-app/README.md) should be available, this should be setup [like this](./setup-mobile-app.md).**

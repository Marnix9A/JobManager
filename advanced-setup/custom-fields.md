# Custom Fields

JobManager offers a range _Custom Fields_, which can be used as desired. This table provides the ability to change **Caption** for these fields.

The lines in this table is [automatically created](../general-setup/jobmanager-foundation-setup-guide.md).

Value fo the fields can be updated by [Code Hooks](./code-hooks.md) or [Custom signing functions](./custom-signing-functions.md). Using this option **avoids** changes to JobManager objects, making updating JobManager versions much easier.

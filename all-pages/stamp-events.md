# Stamp Events

Overview of all [Stamp Events](../all-tables/stamp-events.md).

The lines can be posted manually in the NAV. Read [here](../daily-use/post-to-nav-bc.md) regarding automatic posting.

Features:

| Function | Description |
| :-- | :-- |
| Journal Stamps | Show the related Stamp Journal, |
| Change status to Waiting | Change the [status](../all-tables/status.md) to **Waiting**. |
| Change status to Skip | Change the [status](../all-tables/status.md) to **Skip**. |
| Manual post | The line are posted in NAV using Journals. |
| Manual post (journal only) | Journal Line(s) are made in NAV Journal, but the Journal **are not** posted. This function is useful if there are errors, which can only be found/corrected by looking at the Journal Line(s). **Use with caution, since the user must manually post the Journal!** |

**For further details see the [table](../all-tables/stamp-events.md).**

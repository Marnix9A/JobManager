# Active Jobs

Displays a list of jobs in progress. The list includes a number of functions that can be performed on these jobs.

**Appearance and features may vary depending on configuration!**

| Function | Short-cut | Description |
| :-- | :-- | :-- |
| Up |  | Move up (previous line). |
| Down |  | Move down (next job). |
| [Reporting](./report-page.md) | Ctrl+Alt+R | Report Status and Qty for the Job. |
| Finish all | Ctrl+Alt+F | Report _all_ active jobs as finished. [Further help](../advanced-setup/stop-code.md) |
| Stop-time all | Ctrl+Alt+S | Stop collecting time for _all_ active jobs. [Further help](../advanced-setup/stop-code.md) |
| Fill Qty Good | Ctrl+Alt+G | Automatic report [Output](../all-tables/report-good.md) on the remaining Qty. |
| [Item Consumption](./item-consumption.md) | Ctrl+Alt+L | Report consumption of Items. |
| [Output (Specification)](./output-specification.md) | Ctrl+Alt+O | Report [Output](../all-tables/report-good.md) with Specification (Location, Bin, Lot, Serial) |
| Show All |  | Show _all_ jobs for the day. Thus the ability to report [Output](../all-tables/report-good.md) or [Item Consumption](./item-consumption.md) on previous registrations. |
| More Functions |  | There may be associated additional special functions. |

# Priority

Here [JobManager Jobs](../general-setup/jobmanager-job.md) can be prioritized. The [Sorting by Priority](../other-features/sorting-by-priority.md) field on _JobManager User Interface_ determines _if_ jobs should be displayed in that order in pages for time registration.

Jobs can be prioritized on a Date and/or Priority.

If a number is entered in the _Priority_ field, then it's a _global_ priority across dates.

If a number is entered in a data column, then it's a priority within the day. The _Priority_ field then shows the number and date in combination.

Priority on a date can also be done by typing _number + space + date_ (`123 12-12-2020`) in the first _Priority_ field.

If you have filled in one priority for a date, you can quickly prioritize the next by doing one of the following:

*   Press _spaces_ in a field below a date
*   Touch the small `...` icon in a field below a date

`The priority field can take the value 0 to 1999999999.`

_In the database, "empty" Priority is saved as "2000000000" and "empty" date as "31st. December 9999"._

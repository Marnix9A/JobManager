# Planned Absence

Here the employee can _see_ and/or _request_ e.g. future holidays.

Use the **New** button to _request_ absence.

Use the **Remove** button to delete/remove a request. If a request is _already_ approved, then **Remove** will be converted to a deletion request.

It is now possible to show a balance by an Absence request, if setup on the IPC.

| Color and font | Description |
| :-- | :-- |
| Orange | New request. |
| **_Red (bold+italic)_** | Rejected request. |
| **Green (bold)** | Approved request. |
| Black | Normal planned absence. |
| _Red (italic)_ | Request for deletion. |

# JobManager

Here is a description of all available job Cue Indicator for JobManager. What is currently displayed may depend on the Role Center.

| Cue Indicator | Description |
| :-- | :-- |
| Job Queue Error | Show the status for the Job Queue regarding auto post. |
| Posting Error | Count the number of Stemp Events with status _Error_. |
| Posting Queue/Waiting | Count the number of Stemp Events with status _Queue_ or _Waiting_. |
| Posting Postponed | Count the number of Stemp Events with status _Postponed_. |
| Messages | Count the number of [messages](./message.md) to the Employee. |
| Calculation missing | Count the number of Employes/Days waiting for [Time Calculation](./time-calculation-and-approval.md). |
| Approvement missing | Count the number of Employes/Days waiting for [Approval](./time-calculation-and-approval.md). |
| Pre-Approvement missing | Count the number of Journal Lines waiting for [Pre-Approval](../other-features/pre-approval.md). |
| Absence Request | Count the number of unanswered Absence Requests. |
| Last Operation finished | Count the number of Productions, where the last operatin in the Route is _Route Status=Finished_. |
| Finished Assembly Orders | Count the number of Assembly Orders [ready for posting](./assembly-orders-jobmanager.md). |
| Active IPC | Show all active registrations on IPC jobs. |
| Active Productions | Show all active registrations on Production jobs. |
| Active Assembly | Show all active registrations on Assembly jobs. |
| Active Jobs | Show all active registrations on Job jobs. |
| Active Service | Show all active registrations on Service jobs. |

# Mail a file

You can mail multiple files.

1. Select the file(s).
2.  Click ![](<../../.gitbook/assets/image (455).png>) .

    An email, with your file(s) in an attachment, opens in Outlook.

    When you don't have Outlook on your computer, the file 'message.msg' downloads to your default download location.

    Tip: When you don't have Outlook, it might be more convenient to download the file(s) first and attach it (them) later to a mail message in your regular email client.

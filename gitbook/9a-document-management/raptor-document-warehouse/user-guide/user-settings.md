# User settings

## Switching between tenants

Environments in Raptor are called 'tenants'. Any Raptor user can access their tenants by logging in the Raptor standalone web application (https://raptor.9altitudes.com).

When using Raptor directly in the browser, you're able to switch between the tenants that you have access to. To switch to a different tenant, click the name in the top right.\
This will open a dropdown that you can choose from.

## Changing the language

To change the language of the user interface:

* Click your name on the top right.
* Click > **Preferences** > **Language**.
* Select the desired language.

## Changing the default tenant

The default tenant will be tenant that is loaded by default when logging into Raptor in the browser. To change your default tenant:

* Click your name on the top right.
* Click > **Preferences** > **Default tenant**.
* Select the desired tenant.

## Resetting default layout settings

Resetting the default layout settings will remove any made customizations to the Document Warehouse view, such as table columns and grouping.

To reset the layout:

* Click your name on the top right.
* Click > **Preferences**
* Click **Reset to default layout settings**

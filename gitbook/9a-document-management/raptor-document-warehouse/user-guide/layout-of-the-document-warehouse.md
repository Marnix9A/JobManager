# Layout of the Document Warehouse

The Raptor Document Warehouse is visualized both standalone and through external systems via the web application available at [https://raptor.9altitudes.com](https://raptor.9altitudes.com/).\
\
For a description of all components of the Document Warehouse layout, see below:

<figure><img src="../../.gitbook/assets/Raptor layout documentation (1).png" alt=""><figcaption></figcaption></figure>

<table><thead><tr><th width="69.2000732421875" data-type="number">N°</th><th width="173.800048828125">Name</th><th>Description</th></tr></thead><tbody><tr><td>1</td><td>General search bar</td><td>Use the general search bar to find documents by filename or tag. <br>To search documents by filename, simply fill in the filename and hit enter.<br>To search a tag and filter on it, fill in the name of the tag and select one of the suggested values.</td></tr><tr><td>2</td><td>Action bar</td><td>The action bar provides all available actions for the currently selected document(s). Options include deleting, downloading, viewing the document in an external tab, generating an email for the document or copying a Raptor link to this document.<br>You can also upload new documents via the 'Upload' button using the file explorer or a document URL.<br><a data-mention href="../configuration/document-triggers.md">document-triggers.md</a> will also appear in the action bar.</td></tr><tr><td>3</td><td>Filters</td><td>The filter bar will display active filters on your document warehouse view. Filters can be a filename search, a tag or a query. If no filters are active, all documents which the user has access to will be shown.</td></tr><tr><td>4</td><td>View options</td><td>Allows the user to display documents as a flat list, or in a thumbnail view.</td></tr><tr><td>5</td><td>Document list</td><td>Displays matching the filter criteria. Columns can be customized using the column configurator.</td></tr><tr><td>6</td><td>Notification bell</td><td>The notification bell will turn blue when a notification or error occurred. Click the bell to view notifications.</td></tr><tr><td>7</td><td>Tenant name</td><td>The name of your Raptor environment, aka tenant. In the standalone web application, clicking the tenant name allows you to switch to other tenants.</td></tr><tr><td>8</td><td>User options</td><td>Displays the currently logged in user. Clicking your username offers you several options such as changing preferences, opening the current Help page and signing out. <br>If you're an administrator, you will also see the option to navigate to the Configuration panel.</td></tr><tr><td>9</td><td>Details pane view options</td><td>Determines which info you want to see in the Details pane.<br>Click 'Detail' to see metadata and tags.<br>Click 'View' to see a rendered image in the document viewer.<br>Click 'Audit' to see the document's audit trail.</td></tr><tr><td>10</td><td>Document info</td><td>Displays the filename, upload date and uploader of the currently selected document.</td></tr><tr><td>11</td><td>Document tags</td><td>Displays all tags that were added to the document.<br>Tip: double click a tag to quickly add it to your filters.</td></tr><tr><td>12</td><td>Document template</td><td>Displays the metadata template assigned to the document. A template can consist of text, number, date and tag fields.<br>Tag fields offer a filtered view of the Document tags section for a quick overview.<br>You can select a template by choosing one from the dropdown.</td></tr><tr><td>13</td><td>Extra fields</td><td>Displays fields added to the document, which are not part of the Document template. You can add additional fields by selecting from the dropdown, or removing them by clicking the Trash icon.</td></tr><tr><td>14</td><td>Advanced search</td><td>The advanced search allows you to create complex queries that go beyond simple searches with the General search bar.<br>Queries can be saved and reused, or shared with a specific security role.</td></tr><tr><td>15</td><td>Raptor CoPilot</td><td>The Raptor CoPilot agent allows you to lookup documents via free text format, which the AI will transform in a search query.<br>Example: 'show me the sales invoices of Q1'.</td></tr><tr><td>16</td><td>Column configurator</td><td>The column configurator allows you to select the columns you wish to display in the document list.<br>The 'Grouping' tab in the column configurator allows you to group your document list on fields to create a folder-like view.</td></tr><tr><td>17</td><td>Refresh button</td><td>Use the refresh button to refresh the document list, to see an updated version of the document or view newly uploaded documents.</td></tr></tbody></table>

# Power Platform & Logic Apps

The **9A Raptor Document Warehouse connector** provides a standardized integration layer between the Raptor document management platform and Microsoft Power Platform services, including Power Automate, Azure Logic Apps, and Copilot Studio. It exposes a set of actions and triggers that allow workflows to interact directly with the Raptor API in a secure and scalable manner.

The connector supports core document management operations such as retrieving documents and metadata, uploading and updating files, and executing repository-specific actions. These operations can be embedded into automated flows, enabling event-driven and scheduled processes that interact with the document warehouse as part of larger enterprise integrations.

For details, refer to the official documentation:\
[https://learn.microsoft.com/en-us/connectors/raptordocmanagement/](https://learn.microsoft.com/en-us/connectors/raptordocmanagement/)

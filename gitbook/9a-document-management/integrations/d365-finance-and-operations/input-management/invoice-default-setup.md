# Invoice default setup

You can manage the default invoicing setup at the path **9A Raptor DWH > Setup > Input management > Invoice default setup.** There you can edit the default value for the item sales tax group. This can then be applied using the invoice setup rule engine.

The security privilege for this feature is 'To maintain Ex Arte invoice default setup'.

### Setting default invoice values for specific vendors

When going to your vendors (**Accounts payable > Vendors > All vendors**), you will see a new menu item  to add default values for the default invoice setup for a specific vendor.<br>

<figure><img src="../../../.gitbook/assets/image (269).png" alt=""><figcaption><p>Screenshot of the 'All vendors' screen highlighting the new menu item 'Invoice default setup'</p></figcaption></figure>

Once you click on the aforementioned menu item, you'll land on the same default invoice setup page, but for that vendor specifically.

On this screen you have 2 parameters:

* Override default settings
* Item sales tax group

You need to enable the 'override default settings' to be able to edit any of the other settings on the page. If it is not toggled on, the default, non-vendor specific setup wil be used when using default invoicing.<br>

<figure><img src="../../../.gitbook/assets/image (270).png" alt=""><figcaption><p>Screenshot  of the vendor-specific default invoicing setup page, highlighting not being able to edit the values when the 'override default settings' toggle is not toggled on</p></figcaption></figure>

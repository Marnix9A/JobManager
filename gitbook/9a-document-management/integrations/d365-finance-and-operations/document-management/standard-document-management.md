# Standard document management

Raptor is able to integrate seemlessly with the standard document handling framework of D365F\&O. This hybrid solution allows you to upload documents to the D365 document handling engine while storing the actual file in Raptor, ensuring that documents are visible in both places without any information being duplicated.

To set this up, create a document type with the class set to _Attach file_. For the location, choose _9A Raptor Document Warehouse_ as the external storage option.

# Available entities: operations

Raptor is now integrated with projects, production, assembly and service in BC. The functionalities are available on the following entities.&#x20;

## Projects (jobs)

Project Card list and card

* Documents linked to the general project order

Project Task Lines

* Navigate to documents linked to a certain task of the project with the 'View Line documents' button
*

    <figure><img src="../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

Project Planning Lines

* Navigate to documents linked to the planning lines of the project. The viewer is available on both the general overview of all the planning lines of the project, and the planning lines of a certain task
*

    <figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>
*

    <figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>



It is also possible to create purchase orders and sales invoices directly from the project card. You can add the project number to the entity configuration of both the purchase order and the sales invoice ('NAL Job No.'). This allows the project number to be included as a tag on the generated documents.

<figure><img src="../../.gitbook/assets/image (714).png" alt=""><figcaption></figcaption></figure>

## Production&#x20;

Production Order list and card

* Documents linked to the general production order
* Raptor functionalities available on the following types of orders
  * Planned Production Order
  * Firm Planned Production Order
  * Released Production Order
  * Finished Production Order (archive page)&#x20;

Production Order Lines

* Navigate to documents linked to a certain line with the 'View Line documents' button

Production Component Lines&#x20;

* Navigate to documents linked to the components of a certain production order line by clicking on the components action on the line.&#x20;

Production Routing Lines&#x20;

* Navigate to documents linked to the routing of a certain production order line by clicking on the routing action on the line.&#x20;

## Assembly

Assembly Order list and card

* Documents linked to the general assembly order

Assembly Lines&#x20;

* Navigate to documents linked to a certain line with the 'View Line documents' button

## Service

Service Order list and card

* Documents linked to the general service order

Service Order Lines

* Navigate to documents linked to a line on the service item worksheet (Lines > Line > Service Item Worksheet > Lines > manage > View Line Documents)&#x20;

Service Item Lines

* Navigate to documents linked to a certain line on the service order with the 'View Line documents' button (Lines > manage)&#x20;

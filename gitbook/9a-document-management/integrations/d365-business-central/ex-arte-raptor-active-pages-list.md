# Ex Arte Raptor Active Pages List

With the use of ExArte Viewer you can see the corresponding documents attached to a specific customer.

<figure><img src="../../.gitbook/assets/image (608).png" alt=""><figcaption></figcaption></figure>

All pages that are possible to activate/deactivate de iframe or call from button appear filled in table Raptor Setup Active Pages List.

User will only have to choose between the ones available if want to show button and/or iframe directly in page.

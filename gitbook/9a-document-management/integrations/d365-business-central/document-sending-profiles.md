# Document Sending Profiles

Use document sending profiles when using the send on mail action.&#x20;

**1) Create a profile that is linked to raptor**

* Go to the document sending profile - page
* Create a profile where the Raptor field is set to 'Yes'. This ensures that the document is automatically linked to Raptor before the email is sent.&#x20;

<figure><img src="../../.gitbook/assets/image (157).png" alt=""><figcaption></figcaption></figure>

**2) Link the profile to your entity (customer or vendor)**&#x20;

* Apply the profile for every customer and vendor you wish on their respective cards&#x20;

<figure><img src="../../.gitbook/assets/image (172).png" alt=""><figcaption></figcaption></figure>

* Or set the RAPTOR-profile as the default on the document sending profile - card&#x20;

<figure><img src="../../.gitbook/assets/image (173).png" alt=""><figcaption></figcaption></figure>

**3) Send the document**

<figure><img src="../../.gitbook/assets/image (174).png" alt=""><figcaption></figcaption></figure>

* All the settings from the document sending profile are copied. &#x20;

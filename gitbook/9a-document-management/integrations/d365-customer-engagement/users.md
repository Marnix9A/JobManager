# Users

## Adding a user to Raptor

To allow users to use Raptor from your D365 CE environment, check the following:

1. The user has the security role 'Raptor Basic User'
   1. This can be done via the Microsoft 365 admin center: [https://learn.microsoft.com/en-us/microsoft-365/admin/add-users/add-users?view=o365-worldwide](https://learn.microsoft.com/en-us/microsoft-365/admin/add-users/add-users?view=o365-worldwide)
2. The user is added in Raptor ([users.md](../../raptor-document-warehouse/configuration/users.md "mention"))
3. The user was assigned the External System configured in the [environment-setup.md](environment-setup.md "mention")

# Work Type

_Work Type_ can be entered when register time using [JobManager - Time Sheet](../daily-use/jobmanager-time-sheet.md) and [JobManager - Time Sheet (Week)](../daily-use/jobmanager-time-sheet-week.md), and is passed on to the [calculated lines](./calculated-lines.md).

Calculation of pay counters, can then be limited to a certain _Work Type_.

Changing a registration from one Job Id to another, with different Work Type, now prompt to confirm overwrite with new value. This applies to "Registration approval" and "Time Calculation and Approval" pages. Before the system only overwrite if value was blank - else nothing overwritten.

For complex setup this [**filter** field](./work-type-filter.md) can be used instead.

# Ref. Number

Indicates the related number depending on the field **Ref. Type**:

| Ref. Type | Ref. Number |
| :-- | :-- |
| IPC | No. of the IPC Category |
| Production | No. of the Production Order |
| Job | No. of the Job |
| Service | No. of the Service Order |
| Assembly | No. of the Assembly Order |

# Allow Feedback

How can the employee report on this Job.

The following rules apply by default.

Quantity can be applied for jobs of type:

*   Production (Process Run)
*   Assembly Order

Status can be changed for _(completed/finish)_ for jobs of type:

*   Production
*   Job
*   Service
*   Assembly Order

The rules can be overridden with the **Edit** function on the _JobManager Jobs_ list, or with code by using [OnAfterInsertUpdate???2JobMan](../advanced-setup/code-customization.md).

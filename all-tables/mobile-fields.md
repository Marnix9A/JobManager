# Mobile Fields

The table contains a list of the possible fields associated with each [page and list](./mobile-pages.md) in the mobile solution.

_The table has previously been referred to as: App Fields._

Each field can be configured with:

*   Show / hide
*   Sort the desired display order fo fields
*   Width
*   Include in search
*   Prefix with Caption

The order in which data appears in the lists can be changed from the code with subscribe to events from Codeunit _JobManNavEventPublisher_.

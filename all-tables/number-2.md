# Number

Indicates the related number depending on [Type](./type-2.md).

| Type | Number |
| :-- | :-- |
| Time Counter | Number from [Time Counter](../jobmanager-calculations/time-counters.md) |
| Pay Type | Number from [Pay Type](../payroll-setup/pay-type.md) |
| Lessor | Number from _Lessor Pay Type_ |
| Codeunit | _Blank_ |

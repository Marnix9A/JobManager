# Only IPC

This field indicates that the employee is only used for simple time registration during this activation.

There is a special type of license for these employees.

The Employee is limited to only registering _Absence_, _Trigger_ and one _IPC_. The _one_ IPC is specified in the field [Only IPC (Job Id)](../general-setup/only-ipc-job-id.md) on the [JobManager Setup](../general-setup/jobmanager-setup.md) table.

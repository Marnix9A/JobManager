# Work Type  (filter)

With the selection of a **filter** for _Work Types_, the counter can be restricted for the selected _Work Types_ assigned to one or more employees.

For simple setup, **one** _Work Type_ can be selected in [this field](./work-type.md) instead.

**Read [here](../all-articles/filter-input.md) to learn about the _syntax_ for filters.**

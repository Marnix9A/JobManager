# Time Schedule Shifts

It is possible to specify multiple shifts in a time schedule. The clock-in registration is used to determine the correct shift.

_Shifts are named 1, 2, 3..._

If there are several _shifts_ on the time schedule, _shift_ on the employee card must be empty.

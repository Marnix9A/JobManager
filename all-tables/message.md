# Message

Here you can see messages targeting the employee or the current PC/terminal.

A message can be sent from one employee to another employee, or to a group of employees.

In principle, an employee can send to other employees, the associated calculation group, or the PC/terminal (NAV/BC user) where registration is made.

Other NAV/BC users (eg. a foreman) can from the Role Center send to all employees, all Calculation Groups and all terminals (NAV/BC users). This requires that the current User is specified on the corresponding [JobManager Employee](../general-setup/jobmanager-employee.md) in the field [User Name](../daily-use/user-name.md).

A message can only be deleted by the sender.

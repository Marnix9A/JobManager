# Enable relations

Questions can be [enabled](./enable-if-question.md) based on the answer on _other question_. If that _other question_ is of [type](../daily-use/type.md) _Option_, this field decide whether the answer enables the question.

**Alternative to specifying the _rule/outcome_ on the question _here_, is to specify it on the _depending question_ in the [Special rule (enable)](./special-rule-enable.md) field.**

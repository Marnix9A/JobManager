# Activity (Approved (Trigger))

It is possible to approve a _calculation error_ in [Time Calculation and Approval](../all-pages/time-calculation-and-approval.md).

You approve the error by pressing _no_ in the warning/error factbox.

_No_ changes to _yes_ and the [Approved trigger](./approved-trigger.md) is automatically inserted into _Stamp Journal Line_

Can e.g. be used for a balance that has gone into red, or an extra approve when the employee has overtime.

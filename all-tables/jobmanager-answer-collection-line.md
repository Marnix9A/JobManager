# JobManager Answer Collection Line

The table _Answer Collection lines_ contains the answers to the individual questions associated with [Answer Collection](../daily-use/jobmanager-answer-collection.md).

All attributes from the individual [Questions](../daily-use/jobmanager-question.md) are copied to this table. This makes answering independent of corrections to the original Question.

An overview of the JobManager Questionnaire Module can be found [here](../daily-use/questionnaire.md).

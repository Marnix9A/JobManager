# Pay API

This table show all API's (**A**pplication **P**rogramming **I**nterface) for Pay, which is installed in JobManager.

A _Pay API_ can be used for:

*   override the the field [Seniority Date](../general-setup/seniority-date.md) on JobManager Employee.
*   _table lookup_ in the field [External No.](../payroll-setup/external-no.md).
*   the _generic_ [Pay Export Type](../payroll-setup/pay-export-type.md) _API transfer Pay_

For the development of a new API, the relevant [published functions](../advanced-setup/code-customization.md) should be used.

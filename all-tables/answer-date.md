# Answer (Date)

| Type | Potential answers |
| :-- | :-- |
| Text | A text with the maximum length of 250 characters |
| Integer | A number _without_ decimals. |
| Decimal | A number _with_ decimals. |
| Option | Choose one or more values from a list of options |
| Date | A date |
| Time | A time of day |
| Date and time | A date and time in one field |

**Answers can be limited with the fields [Minimum (validation)](./minimum-validation.md) og [Maximum (validation)](./maximum-validation.md).**

# Qualification Code (filter)

With the selection of a **filter** for _Qualification Code_, the counter can be restricted for the selected Qualification assigned to one or more employees.

For simple setup, **one** _Qualification Code_ can be selected in [this field](./qualification-code.md) instead.

**Read [here](../all-articles/filter-input.md) to learn about the _syntax_ for filters.**

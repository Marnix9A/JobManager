# Pay Type Qty

To make [manually adjustment](../other-features/adjust-time-counter.md) the following fields applies:

*   **Profiledato** indicates the desired dato for the adjustment.
*   **Time** indicates the value to adjust the Time Counter.
*   **Pay Type for Adjustment** fill out if [Pay Entrty](./pay-events.md) should be made.
*   **Pay Type Qty** fill out if [Pay Entrty](./pay-events.md) should be made.

If **Time** is entered without specifying **Pay Type Qty**, the Time Counter is adjusted _without_ [Pay Entry](./pay-events.md) made.

If **Pay Time Qty** is entered without specifying **Time**, a [Pay Entry](./pay-events.md) is made _without_ affecting the Time Counter.

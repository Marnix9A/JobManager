# Maximum (enable relations)

Questions can be [enabled](./enable-if-question.md) based on the answer on _other question_. The [type](../daily-use/type.md) of that _other question_ decide whether the answer enables the question.

| Type | Answer enables _other question_ if |
| :-- | :-- |
| Text | Length of the text is within minimum and maximum _(enable relations)_ |
| Integer | The value is within minimum and maximum _(enable relations)_ |
| Decimal | The value is within minimum and maximum _(enable relations)_ |
| Option | [Special rule](./enable-relations.md) |
| Date | n/a |
| Time | n/a |
| Date and time | n/a |

**Alternative to specifying the _rule/outcome_ on the question _here_, is to specify it on the _depending question_ in the [Special rule (enable)](./special-rule-enable.md) field.**

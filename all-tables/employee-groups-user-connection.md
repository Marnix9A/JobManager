# Employee Groups User Connection

It is possible to Assign multiple Responsible persons to a Calculate/Approve group

The setup is made by marking the actual _Employee Group_ and choose _User Connection_. A line is made for every user, with checkmark in the field _Responsible_.

Simultaneously it is possible to use _Security Filters_, where it is delimited for Calculator /Approver to filtrate into groups, where they are not _Responsible_

If Security Filters is active it is only nessecary that one user, has checkmark ind _Responsible_, other which is allowed to se the employees in the group is just marked in the field _Security filter_

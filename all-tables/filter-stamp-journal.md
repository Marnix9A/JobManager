# Filter Stamp Journal

This field can further narrow search in [Stamp Journal](./stamp-journal-lines-2.md) for the selected _Job Id_.

*   **All** for failing filter
*   **Only Auto** to check only the [Stamp Journal](./stamp-journal-lines-2.md) made by the Employee in the eg. [JobManager - Registration Client](../daily-use/jobmanager-registration-client.md).
*   **Only Manual** to check only the [Stamp Journal](./stamp-journal-lines-2.md) entered manually in eg. [Time Calculation and Approval](../all-pages/time-calculation-and-approval.md).

Note: This field applies only to the [Type](./type-3.md) of **Job Id (present)**.

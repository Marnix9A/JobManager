# Statistics Column Set

The Column Set, can be setup for the following pages/reports:

*   [Registration Approval](../daily-use/registration-approval.md)
*   Statistic (Registration options and JobManager Employee Card)
*   Statistics Column(Report)
*   Specifications of Time and Payment (Report)

When the **Foundation Setup Guide** runs, there automatically creates examples for Colums and Columns Set for e.g. _Registration approval_  
Other Columns can be setup [here](N_6182308.htm) and can afterwards be setup in desired order in the Column Set.

In [Relation](./statistics-column-set-relation.md) the setup for which Page/Report is set up.

# JobManager BI Group

This table contains the setup used by the [standard Power BI reports](../advanced-setup/power-bi.md) provided with JobManager.

The specified options must be assigned to the respective fields in selected tables:

*   [BI Group](../jobmanager-calculations/bi-group.md) on the [Time Counter](../jobmanager-calculations/time-counters.md) table
*   [BI Group](../payroll-setup/bi-group.md) on the [Pay Type](../jobmanager-calculations/time-counters.md) table
*   [BI Group](../payroll-setup/bi-group.md) on the [JobManager BI Mapping](T_6182368.htm) table

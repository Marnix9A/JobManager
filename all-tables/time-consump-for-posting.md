# Time Consump for posting

The field specifies how registrations are [posted to NAV](../daily-use/post-to-nav-bc.md).

The field is inherited from the same field on [JobManager Job](../general-setup/jobmanager-job.md).

| Option | Action |
| :-- | :-- |
| Standard | Posting the time from this field [Time Comsump](./time-comsump.md). |
| Stamp Time (Gross) | Posting the time from this field [Stamp Time (Gross)](./stamp-time-gross.md). |
| Stamp Time (Net) | Posting the time from this field [Stamp Time (Net)](./stamp-time-net.md). |

The value can be adjusted with [this field](./factor-for-posting.md).

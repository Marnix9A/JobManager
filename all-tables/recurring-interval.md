# Recurring Interval

Ability to set automatic recurring. Specify for example **8D** the line will continuously be automatically copied/forwarded _8 days_ ahead.

Several lines can use this option. This makes it possible to make a pattern eg: _10 days 12 hours, 5 days off work, and so on_.

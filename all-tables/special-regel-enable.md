# Special regel (enable)

When using [Enable if Question](./enable-if-question.md) the _rule (value)_ (with this field) be set on the dependent question in _this_ field.

If _nothing_ is specified here, the value must be set to the opposite question in the following fields:

*   [Minimum (enable relations)](../daily-use/minimum-enable-relations.md) on questions specified in [Enable if Question](./enable-if-question.md)
*   [Maximum (enable relations)](../daily-use/maximum-enable-relations.md) on questions specified in [Enable if Question](./enable-if-question.md)
*   [Minimum (enable relations) - Formula](../daily-use/minimum-enable-relations-formula.md) on question specified in [Enable if Question](./enable-if-question.md)
*   [Maximum (enable relations) - Formula](../daily-use/maximum-enable-relations-formula.md) on question specified in [Enable if Question](./enable-if-question.md)
*   [Enable relations](./enable-relations.md) under _Options_ on question specified in [Enable if Question](./enable-if-question.md)

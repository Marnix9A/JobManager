# Enabled

Specify whether the question should be enabled based on the answer from _other question_. ID for that _other question_ is indicated in this field.

The type of _this other question_ determines if the answer should [enable](../daily-use/minimum-enable-relations.md) the question.

The answer from that other question can be _reversed_ with the field [Not TRUE](./not-true.md).

**Alternative to specifying the _rule/outcome_ on _the other question_, is to specify it _here_ on this line in the field [Special rule (enable)](./special-rule-enable.md).**

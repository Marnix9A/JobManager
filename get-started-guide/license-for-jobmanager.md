# License for JobManager

An JobManager Employee Licens is required for everyone created in the JobManager Employee table, and which is [listed as active](T_5182317.htm). This applies both to _real_ employees, and if _machines_ are created in this table.

Licensed JobManager Employees are counted in every company. Though companies starting with _CRONUS_ are excluded from this.

For SaaS installations only _Production_ environments counts.

At the bottom of the _JobManager Setup_ page there is a section which shows the number of active employees _in the current company_.

*   Press the number to see a list of the active employees.
*   Press _Total Active Employees_ to see count for all Companies (this requires the user to have rights to all relevant Companies).

_Note: If an Employee is present in several Companies, payment must be made for all._

**Several times a month, NAV/BC automatically report the number of Active Employees via the Internet. It is only the Company informations and a count - thus sensitive information about the individual Employees is NOT sent.**

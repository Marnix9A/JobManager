# Get started guide

Below is a list of the steps that should be undertaken for the successful importation of JobManager.

**TIP: Read [here](../advanced-setup/make-demodata.md) to learn how to make demodata for Cronus.**

| Step | Description | Run |
| :-: | :-- | :-- |
| 1 | Run the Guide [JobManager Foundation Setup Guide](../general-setup/jobmanager-foundation-setup-guide.md) | Open the page **JobManager Setup** and select **JobManager Foundation Setup Guide** |
| 2 | [Parameters setup](../general-setup/jobmanager-setup.md) in JobManager | Open the page **JobManager Setup** |
| 3 | Run [Set default permissions](../other-setup/set-default-permissions.md) **(Note 1)** | Open the page **JobManager Setup** and select **Set default permissions** |
| 4 | [Users and Permissions](../other-setup/set-default-permissions.md) and [Role Center](../other-setup/role-center.md) | [Create Users](https://docs.microsoft.com/en-us/dynamics365/business-central/ui-define-granular-permissions) og [Assign Role Center](https://docs.microsoft.com/en-us/dynamics365/business-central/admin-users-profiles-roles) |
| 5 | Customize [User Interface](../other-setup/jobmanager-user-interface.md) | Open the page **User Interface** |
| 6 | Import demo [Calculation](../jobmanager-calculations/import-export-calculation.md) | Open the page **Calculations** and select **Download online** |
| 7 | Create relevant [Periods](../general-setup/period.md) and [Calculation & Approval Groups](../general-setup/employee-groups.md) | Open the pages **Periods** and **Employee Groups** |
| 8 | Create [Employees](../general-setup/employee-setup.md) i Human Resources | [Create Employees](https://docs.microsoft.com/en-us/dynamics365/business-central/hr-how-register-employees) |
| 9 | Assign Employees to [JobManager Employees](../general-setup/employee-setup.md) | Open the page **JobManager Employees** |
| 10 | Update relevant [Jobs](../general-setup/jobmanager-job.md) to Procuction, Job, Service and Assembly. | Open the page **JobManager Jobs** and select **Update Jobs** |

**Note 1: If JobManager is installed as an Extenstion/APP, these Permission Sets already exists (as they are part of the installation).**

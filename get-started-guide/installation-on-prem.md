# Installation (On-Prem)

This help pages es intended for installing on Dynamics Business Central On-Premise. From JobManager version 02.00 and above, the extention is supported on BC14 and forward.

The following steps will take you through the installation of JobManager:

**OBS: From JobManager 01.33 a new NAV/BC Partner and Customer License are required. Re-download both Licenses from Microsoft Portal if license is older than 4th of August 2023.**

# Installation

1.  The installation file (JobManager\_X.XX.XXXXXX.X) is located in the _Install\_V2\_Extension_ folder of downloaded ZIP.
2.  If Lessor PayRoll is already installed (applies only to BC 13 and BC 14), then install the JobManager\_Lessor extension as well (JobManager\_Lessor\_X.XX.XXXXXX.X).
3.  OPTION: Install the font _BC C39 3 to 1 Narrow_ if you want to print barcodes from JobManager. Install on both NAS/NST server and relevant clients. The font is located in the barcode subfolder of installation kit. Right-click and choose to install.
4.  From within Dynamics Business Central run [JobManager Foundation Setup Guide](../general-setup/jobmanager-foundation-setup-guide.md) for each company (found as a menu action in the page JobManager Setup.
5.  Read the [Get started guide](./README.md) within JobManager for further actions.

### Special requirements for infrastructure:

*   JobManager has no special requirements.
*   It can be installed on version 14 and above.
*   The installation is independent of Cumulative Updates.
